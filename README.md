# Premiere Pro Auto Edit Tool

Automated video editing toolkit for Adobe Premiere Pro using ExtendScript and PowerShell.

## Features

- Automated clip editing via ExtendScript (.jsx)
- PowerShell automation for launching and managing Premiere Pro
- Preprocessing pipeline for clip preparation
- Quick edit workflow for common tasks

## Files

- `auto_edit.jsx` - Main auto-editing ExtendScript
- `quick_edit.jsx` - Quick editing workflow
- `preprocess_clips.ps1` - Clip preprocessing PowerShell script
- `launch_and_run.ps1` - Launch Premiere Pro and run scripts
- Check environment and run scripts via .bat files

## Usage

1. Open Premiere Pro
2. Run `运行自动剪辑.bat` or execute the .jsx scripts from ExtendScript Toolkit
3. Use PowerShell scripts for batch processing

## Requirements

- Adobe Premiere Pro
- ExtendScript Toolkit (or VS Code with ExtendScript extension)
- PowerShell
