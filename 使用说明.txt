         Premiere Pro 自动剪辑脚本 - 使用说明
═══════════════════════════════════════════════════════════════

【文件说明】
- quick_edit.jsx    : 快速剪辑脚本（推荐使用）
- auto_edit.jsx     : 完整功能版本
- 使用说明.txt       : 本文件

【使用方法】

方法一：在 Premiere Pro 中运行
1. 打开 Adobe Premiere Pro 2022
2. 点击菜单：文件 → 脚本 → 运行脚本文件
3. 选择 quick_edit.jsx 文件
4. 等待脚本执行完成

方法二：直接双击运行（如果关联了 Premiere Pro）
1. 双击 quick_edit.jsx 文件
2. Premiere Pro 会自动打开并执行脚本

【脚本功能】

自动完成以下操作：
✓ 创建新项目
✓ 导入 E:/PR作品/ 中的视频素材
✓ 创建 1920x1080 30fps 序列
✓ 将素材添加到时间线（每个片段4-6秒）
✓ 添加交叉溶解转场（0.5秒）
✓ 添加文字标题（白色，半透明背景）
✓ 添加音频淡入淡出效果
✓ 保存项目文件

【素材列表】

脚本会自动导入以下素材：
1. Counter-Strike 2 2026-01-11 03-52-23.mp4 (5秒)
2. Black Myth Wukong Trim_1.mp4 (6秒)
3. 1tap(1).mp4 (4秒)
4. Anime Edit Zenitsu Demon Slayer 4_1.mp4 (5秒)
5. Desktop 2025.05.28 - 03.20.22.02.mp4 (4秒)

总时长：约24秒

【自定义修改】

如需修改素材或参数，编辑 quick_edit.jsx 文件中的：

1. 修改素材列表（第12-18行）：
   var CLIPS = [
       { path: "你的视频路径", name: "名称", start: 开始秒数, duration: 持续秒数 },
       ...
   ];

2. 修改输出路径（第20行）：
   var OUTPUT_PATH = "你的输出路径/";

3. 修改项目名称（第21行）：
   var PROJECT_NAME = "你的项目名称";

【导出视频】

脚本执行完成后，需要手动导出：
1. 在 Premiere Pro 中，点击 文件 → 导出 → 媒体
2. 选择格式：H.264
3. 选择预设：YouTube 1080p HD
4. 设置输出路径
5. 点击"导出"按钮

或使用 Adobe Media Encoder 批量导出。

【注意事项】

1. 确保 E:/PR作品/ 目录中存在上述视频文件
2. 如果文件路径包含中文，可能需要手动调整
3. 脚本执行过程中请勿操作 Premiere Pro
4. 首次运行可能需要较长时间（导入素材）
5. 如果遇到错误，请检查 Premiere Pro 版本是否为 2022

【故障排除】

问题：脚本无法运行
解决：确保 Premiere Pro 已安装且为 2022 版本

问题：素材导入失败
解决：检查视频文件是否存在，路径是否正确

问题：转场效果不显示
解决：确保序列中至少有2个素材片段

问题：文字标题不显示
解决：检查视频轨道2是否被隐藏
